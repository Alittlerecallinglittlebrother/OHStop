# Slidecasting goat

Slidecasting goat（OHStop）会在读条时帮你稳住脚步，快读完时自动放行；也支持按住快捷键临时移动、自动奔跑保护和状态浮窗。

## 添加独立插件仓库

在 DalamudCN 设置的“自定义插件仓库”中添加：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/OHStop/main/repo.json
```

保存后即可在插件安装器中搜索并安装 `Slidecasting goat`。

## 当前版本

`1.0.19.8`

## 主要功能

- 读条前段移动输入保护，进入滑步窗口后自动放行
- 瞬发技能自动旁路，避免残留移动锁定
- 支持自定义按住快捷键临时放行
- 自动奔跑与地面/飞行移动输入同步处理
- 状态浮窗、实时读条信息和诊断日志

## 包文件

`OHStop.zip` 是可直接供 DalamudCN 插件安装器下载的发布包。
